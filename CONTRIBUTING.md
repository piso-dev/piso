# Contributing

Thanks for your interest in piso.

## This repository is a read-only mirror

`piso-dev/piso` is published automatically from a private upstream
repository. Development, review, and releases all happen upstream. This
mirror is generated: every publish replaces the branch history, so **pull
requests opened here cannot be merged** — any local commit would be
discarded by the next publish.

## How to contribute

- **Issues are welcome.** Bug reports, reproduction cases, and feature
  requests are read and triaged, and relevant fixes are made upstream.
- **Do not open pull requests.** If you have a change, open an issue
  describing the problem and, if you like, link a patch or a fork — it will
  be evaluated upstream and re-authored there if accepted.
- **Security reports:** please do not open a public issue for a
  vulnerability. Report it privately to the maintainers.

## Licensing of contributions

Anything you submit in an issue or as a linked patch is understood to be
offered under the license of this repository. Because this mirror does not
accept commits, no separate contributor agreement is required to open an
issue.

## Why a mirror?

The upstream repository contains internal planning, marketing, and
deployment material that is not part of the public distribution. Only the
product components are published here. See `README.md` for the public
surface.
